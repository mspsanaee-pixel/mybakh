# mybakh

رزومهٔ تصویری مرسدس-مایباخ S680 — یک صفحهٔ HTML تک‌فایلی با پس‌زمینهٔ عکس واقعی خودرو.

## فایل‌ها

| فایل | توضیح |
|---|---|
| `resume-maybach.html` | صفحهٔ رزومه. تصویر پس‌زمینه به‌صورت base64 داخل فایل جاسازی شده است، بنابراین فایل کاملاً مستقل است و بدون پوشهٔ `assets` هم باز می‌شود. |
| `assets/maybach-1.jpg` | تصویر خام پس‌زمینه (نسخهٔ ۱۹۲۰ پیکسل) برای ویرایش‌های بعدی. |

## ویژگی‌ها

- راست‌به‌چپ فارسی، فونت Vazirmatn
- پنل شیشه‌ای با حاشیهٔ طلایی و گوشه‌های تزئینی
- ریسپانسیو برای موبایل
- استایل چاپ A4 با پس‌زمینهٔ سفید و متن تیره

## استفاده

فایل `resume-maybach.html` را در مرورگر باز کنید. برای خروجی PDF از `Ctrl+P` و گزینهٔ
«Save as PDF» استفاده کنید.
